# LiquidVolume 0.29.0

Liquid Glass-inspired styling for Samsung's native compact volume panel.

- Translucent capsule, real Samsung background blur and subtle highlights.
- Speaker icon with a muted state.
- Native volume buttons, dragging, expansion and accessibility retained.
- Corrected low-level drawing and fill alignment.
- Updated interactive Design Studio.

Tested development target: Galaxy S23+ SM-S916B/DS, One UI 9 / Android 17, LSPosed API 102. Other firmware is unverified.

Install the APK, enable LiquidVolume for System UI in LSPosed, then restart SystemUI or reboot. Existing users can update in place with this persistently signed debug APK.

This release attaches the already-tested APK from build 43543496109, commit 3a38461d8a1771fb442496af271d14c9eeafaab7. No application code is changed by publication.
